How It Works in Three Steps 三步完成出证与验证

Online serving adds only lightweight read-only boundary recording; proof generation runs asynchronously in the background and never blocks token streaming. 在线服务只挂一层轻量的只读记录钩子；耗时的零知识证明全部放在回复结束后的后台异步完成，绝不卡住流式输出。

One-Time Weight Commitment模型只承诺一次，永不耗尽

Weights are Reed–Solomon encoded once when published. Each reply proof opens 123 random columns inside the zero-knowledge circuit so static codeword symbols never appear in public transcripts. 模型权重在发布时做一次纠错码承诺；每次出证在零知识电路内部秘密核对 123 列，公开证明里绝不暴露静态码字，因此无论服务多少亿次请求都不会磨损耗尽。

Local Rounding-Contract Checks按硬件算子规则检查浮点误差

Instead of forcing bit-identical integer execution across layers, each sampled block checks the engine's output against its own committed input using the operator's declared rounding bound—preventing cross-layer error blow-up. 不强求跨硬件逐位一致，而是在每个被抽查的算子块上，从引擎自己记录的输入出发算出该算子允许的浮点舍入范围。误差不跨层累积，正常浮点推理 100% 放行，偷换量化或跳层一眼抓出。

Sort-Free Keyed Random Sampling支持真实温度与 top-p 随机采样

A keyed Poseidon2 sponge partitions the vocabulary into 32-token buckets for Gumbel-max selection and inverse-CDF sampling, cutting vocabulary circuit size ~10× while supporting coupled speculative decoding. 用带密钥哈希将词表按 32 词分桶采样，无需全词表排序即可精确支持温度与 top-p 随机生成，把词表电路开销降低约 10 倍，并天然兼容投机解码。
